写真カルテ作成

Excelの一覧表と写真を番号で結びつけて、カルテ(A4)を作ります。データはこのパソコンの中だけで処理され、外部には送信されません。

保存・続きから作業

まだ何も読み込んでいません。

「カルテを保存」で、Excelの内容・写真・手入力した内容をまとめて1つのファイル(.karte)に保存します。次回は「保存したカルテを開く」でそのファイルを選ぶと、続きから作業できます。

1. Excelを読み込む

番号の列:

Excelを書き直したときは、もう一度「Excelファイルを選択」で選び直してください(画像と手入力した内容はそのまま残ります)。

2. 画像を読み込む

番号の取り出し方:

①(表)/②(裏)の決め方:
・フォルダ名やファイル名に「表」があれば①、「裏」があれば②
・それ以外で同じ番号が2枚あれば、ファイル名順に1枚目→①、2枚目→②
・フォルダや画像はこの画面へドラッグ&ドロップでも読み込めます
・あとで差し替えるときは、カルテの写真枠をクリック、または写真枠に画像をドロップ

まだ読み込んでいません。
3. 項目の対応(Excelのどの列をどこに表示するか)

最初はカルテ様式の赤字(A、C、B…)の列が選ばれています。設定はこのブラウザと保存ファイルに記録されます。

4. 印刷・PDFにまとめる

範囲: 〜

印刷画面で「送信先(プリンター)」を「PDFに保存」にすると、全カルテを1つのPDFにできます。用紙A4・余白「なし」・「背景のグラフィック」オンがおすすめです。枚数が多い(数百枚)ときは、範囲を100件ずつ程度に分けると安定します。

0 / 0

カルテの文字欄をクリックすると、直接入力・修正できます(手入力した欄は黄色で表示、印刷には色は出ません)。
