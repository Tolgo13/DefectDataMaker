# 写真カルテ作成(HTML版)

Excelの目録と写真(表・裏)を **番号** で結びつけて、A4のカルテを作るツールです。
`写真カルテ作成.html` をダブルクリックしてブラウザ(Chrome / Edge 推奨)で開くだけで使えます。
インストールもインターネット接続も不要で、データはパソコンの外には送信されません。

## 使い方

1. **Excelを読み込む**:「Excelファイルを選択」で目録(.xlsx)を選ぶ
   - 「番号」と書かれた見出しの行を自動で探します(例: 5行目)
   - Excelを直したときは、もう一度選び直すと反映されます
2. **画像を読み込む**:次のどれかを使う
   - 「画像フォルダを選択(①②自動)」…表と裏が入ったフォルダをまとめて読み込む
   - 「① 表のフォルダ」「② 裏のフォルダ」…表と裏が別のフォルダの場合
   - フォルダや画像をブラウザの画面にドラッグ&ドロップ
3. **項目の対応**:最初はカルテ様式の赤字の列が選ばれています(下の表)。必要なら列を選び直す
4. 「◀ 前へ」「次へ ▶」(またはキーボードの ← →)でカルテを確認する
   - **文字欄をクリックすると直接入力・修正できます**(手入力した欄は画面上だけ黄色になります。Escで入力を取り消し)
   - 写真枠をクリック、または写真枠に画像をドロップすると、その番号の画像だけ差し替えられます
   - 文字が多くて入らない欄は自動で文字を小さくし、それでも入らない分は切れます
5. **全部まとめて印刷 / PDF** を押し、印刷画面で「PDFに保存」を選ぶと、全カルテが1つのPDFになります
6. **カルテを保存**(Ctrl+S):Excelの内容・写真・手入力をまとめて `.karte` ファイルに保存します。
   次回は **保存したカルテを開く** でそのファイルを選ぶと続きから作業できます
   (Excelを直したら「Excelファイルを選択」で読み込み直すと反映され、手入力はそのまま残ります)

## カルテの欄とExcelの列(最初の対応)

| 欄 | 列 | 欄 | 列 |
|---|---|---|---|
| 番号 | A | 名称 | C |
| 旧番号 | B | 原題 | O |
| 紀年 | D | 西暦換算 | AD |
| 朱角印「函號冊」 | Q | 朱角印「第□號」 | R |
| 史料中記載事項 | AA | 紙背記載 | AB |
| 寸法 縦 | G | 寸法 横 | H |
| 料紙 本紙材質 | K | 料紙 紙数 | L |
| 資料補強など | AE | 付属ほか・損傷その他・備考 | (手入力) |

## 番号と①②の決め方

| 例 | 番号 | 入る枠 |
|---|---|---|
| `表/065.jpg` | 65 | ①(フォルダ名に「表」) |
| `裏/065.jpg` | 65 | ②(フォルダ名に「裏」) |
| `67.jpg` と `67_裏.jpg` | 67 | `67.jpg`→①、`67_裏.jpg`→② |
| `70.jpg` と `70-2.jpg` | 70 | ファイル名の順に①、② |

- 番号は、ファイル名の最初の数字です(`065` と `65` は同じ番号として扱います)。
  Excelの番号が `65-1` のような枝番の場合は、「番号の取り出し方」を「ファイル名そのまま」にしてください。
- 損傷(折れ・皺・破れ・欠失)と処置(プレス・補強・補紙)は印刷後に手書きで丸を付ける想定のため、文字だけを表示しています。
- TIFF画像はブラウザで表示できないので、JPEGかPNGにしてください。

# 汎用カルテ作成(HTML版)

表の形を自由に変えられる汎用タイプです。`汎用カルテ作成.html` をブラウザ(Chrome / Edge 推奨)で開いて使います。
最初は「8列×12行の表+備考+写真①②」の形(添付の様式と同じ)になっています。

## 使い方

1. **Excelを読み込む**:見出しの行は「番号」と書かれた行を自動で探し、なければ1行目を使います(手で行番号も指定できます)
2. **項目1〜12に表示する列**:最初は 項目1=A列、項目2=B列 … 項目12=L列。左の表の1〜12行目の左端に入ります
3. **画像を読み込む**:写真カルテ作成と同じです
4. **様式の編集(別ウインドウ)**
   - セルをクリックで選択、**Shift+クリック**で範囲を選択 →「結合」/「結合を解除」
   - セルを**ドラッグして別のセルに落とす**と中身が入れ替わります(例:左の「項目4」を中央へ移し、隣のセルに文字「縦」を入れる)
   - セルの中身は「空欄」「文字(見出しなど)」「項目(Excelの値)」から選べます。揃え・大きさ・太字も変えられます
   - 行の高さ(mm)、備考欄の見出しと高さ、写真の枚数を変えられます
   - **写真を「1枚」にすると、②が消えて①が大きくなります**(左の操作パネルからも切り替えできます)
   - 様式は自動で記録されます。「様式をファイルに書き出す」で .json にしておくと、別の作業でも同じ形を使えます
   - ポップアップが止められているときは、同じ画面の上に編集画面が開きます
5. **ページ番号**:形式(1 / - 1 - / 1 / 全体の数 / p. 1)、位置(下中央・下右・上右)、最初の番号を選べます
6. **印刷・保存**:写真カルテ作成と同じです(保存ファイルは汎用版どうしでのみ開けます)

項目の欄(画面上で赤い「項目○」が出る欄)はクリックして手入力できます。

## ファイルの構成

| ファイル | 内容 |
|---|---|
| `写真カルテ作成.html` | **これを開いて使う**(決まった様式のカルテ) |
| `汎用カルテ作成.html` | **これを開いて使う**(表の形を自由に変えられるカルテ) |
| `karte_src.html` / `generic_src.html` | それぞれのアプリ本体。直すときはこちらを編集 |
| `vendor/xlsx.full.min.js` | Excelを読み込むための部品(SheetJS, Apache License 2.0) |
| `build.py` | 本体を直したあと `python karte_app/build.py` を実行すると、上の2つのHTMLを作り直す |

## 注意

- ページを閉じると、保存していない作業は消えます。閉じる前に「カルテを保存」してください(保存していないと確認が出ます)。
- `.karte` ファイルには写真が元の画質のまま入るので、写真の合計と同じくらいの大きさになります。
- 数百枚を一度に印刷すると重くなるため、「範囲」で100件ずつ程度に分けてPDFにすると安定します。
